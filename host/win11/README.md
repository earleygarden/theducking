# Windows S288 上位机使用入口

## 当前状态

- 实验半成品，主线为 `pose_ui.py`，功能和缺口见 [仓库 README](../../README.md)。
- 提供串口连接、电脑端标零、方向核对、手动调节、位姿回放、实测采集和离线工作台。
- 没有完整整机模型、训练启动器、行走策略或语音功能。

## 安装与启动

- 前置条件：Windows 11、Python；界面依赖 PyQt6，总线依赖 pyserial，离线规划依赖 Ruckig。
- 在仓库根目录执行：

```powershell
python -m pip install -r host/win11/requirements.txt
python host/win11/pose_ui.py --sim
```

- 安装耗时取决于网络和已有依赖，第一次先验证离线界面。
- 正常启动：`python host/win11/pose_ui.py`，在主窗口刷新、选择串口并连接。
- 批处理入口：`.\host\win11\ui.bat`，会处理依赖并转交参数。

| 参数 | 默认值 | 作用 |
|---|---|---|
| `--sim` | 关闭 | 假总线预览，不是物理仿真 |
| `--port COM5` | 未指定 | 指定串口并请求启动后连接，否则手动选择 |
| `--baud` | `6000000` | 波特率 |
| `--ids 7,8,14` | 代码的 14 关节列表 | 本次关节，单台地址 `0–14` 且不重复 |
| `--list-ports` | 关闭 | 列串口后退出 |
| `--title` | `app_config.py` 的标题 | 覆盖标题 |
| `--no-watchdog` | 关闭 | 禁用默认超时保护，不作为常规启动参数 |

## 最小实物操作流程

- 先断电确认电源、线束和实际型号，结构放在固定台架上。
- 首次只选已核对的少量 ID，读取反馈并确认电机对应的真实关节。
- 静止后执行电脑端标零；未标零不能使能。当前不支持机械原点 Flash 写入。
- 从低增益、低速、小行程验证方向，再录位姿。Windows 主线没有机械角度软限位。
- 手动速度是目标角推进速率；真实机械速度受负载、增益和通信周期影响。
- “停止播放”保持最后指令；“急停/全部卸力”请求卸力。零刚度不能替代急停。

## 位姿与运行数据

| 文件 | 含义 | 默认位置 |
|---|---|---|
| `calib_host_xianduck.json` | 本机零位与方向 | 源码入口目录，打包后在 EXE 旁 |
| `poses_xianduck.json` | 位姿库 | 同上 |
| `poses_xianduck.csv` | 导出位姿表 | 保存窗口选择 |
| `log_时间.csv` | 遥测 | 默认在运行数据同目录 |
| `s288_时间_随机后缀/` | 实测会话、原始采样与统计 | 测量窗口选择 |

- 保留已有数据文件名，方便迁移；仓库改名不自动改标定内容。
- 零位变化后旧位姿不能保证相同机械姿态，应逐帧复核。
- JSON 当前版本为 `3`，每帧 `speed` 为 `deg/s`、`dwell` 为秒；CSV 列为 `speed_deg_s`、`dwell_s`。
- 旧 JSON 缺少 `speed` 时按默认值迁移，旧 `trans` 留为 `legacy_trans_s`，首次迁移检查每帧速度。
- 播放按每帧速度推进，参与关节确认到位后暂停；故障、断连、未标零或超时会中止。
- 标定、位姿、测量和遥测默认忽略；共享前先脱敏，放专用示例目录并评审。

## 离线工作台

- 从主界面打开，不需要硬件；已标零反馈只作为打开时快照。
- 支持构型草案、MJCF 根 XML 静态字段和资源检查、每帧停稳的 Ruckig 参考轨迹。
- 未知方向、总线、模型名和策略序号保留待确认，不伪造完整映射。
- 暂停为零也不会连续穿点。模型坐标导出要求完整已确认映射，全部输出 `training_ready=false`。
- 没有动态物理仿真、碰撞认证、训练或策略推理；参考不直接发送电机。

## 打包

```powershell
.\host\win11\build.bat
```

- 默认名在 `app_config.py`，当前为 `unitree_s288_microduck_joint_ui_v1_06.exe`，输出到 `host/win11/dist/`。
- 自定义名：`python host/win11/build.py --name microduck-host-s288`。
- 耗时取决于首次依赖安装和环境，本文不保证固定时间或大小。
- 本轮验证源码离线测试，没有重新构建或签发二进制。
- 同一机器人换电脑时同时迁移匹配零位和位姿，不能只复制 EXE 后假定标定已保留。

## 检查与排错

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
python -m unittest discover -s host/win11/tests -v
```

| 现象 | 先检查什么 |
|---|---|
| 没有串口 | USB、驱动和权限，使用 `--list-ports` |
| 串口无反馈 | 实际端口、电源、适配器、ID 与 `6 Mbps` 支持 |
| 部分在线 | 分段查供电、节点、线束和地址冲突，不自动认定参数问题 |
| 标零失败 | 静止反馈、故障或掉线 |
| 模型检查失败 | 补映射和资源；静态通过仍不代表可训练 |
| 打包失败 | 终端错误和依赖；同步盘锁定时用本机非同步目录构建 |
